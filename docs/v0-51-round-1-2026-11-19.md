- survival-7／community-2 隔離舊排名；新版 session、replay result、board 均包含伺服器推導的 storm。無 SQL migration、無依賴升級或新增排程。

## 效能門檻與限制

第一個候選曾量到 3.9707 秒；core 最初版本約 3 秒，0.51.0.4 又有一次 3.3058 秒，不因挑出較快樣本就判定通過。改用精簡 Canvas 後，0.51.0.5 在 cache disabled、150ms latency、200,000 B/s download、CPU 4×、390×796 iframe 的三次完整冷啟動為 **2.5232／2.5189／2.5257 秒**，均低於 3 秒。開始畫面可操作的代理指標是 canvas、每日標題及啟用的開始控制都存在後的第一個 animation frame。

同候選在 CPU 4× 下跨兩局、20 次原生 keydown 到下一個 animation frame 的 p95 **17.8ms**、最大 **65ms**。此為軟體輸入到下一繪製時機的量測，不是觸控硬體延遲。standalone JS 約 907.33 kB／gzip 408.63 kB；仍有 >500 kB chunk 警告，未以隱藏警告代替量測。初始與最終 viewport 不同，不將結果宣稱為受控環境的速度提升百分比。
