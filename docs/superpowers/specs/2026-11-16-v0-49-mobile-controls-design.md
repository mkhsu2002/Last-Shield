# v0.49 mobile control dock

僅修改 HTML／CSS 呈現，不變動 survival-6、計分、碰撞、操作事件或 community-1 契約。驗證 320–540px 寬、568–900px 高、英文與繁中、充能／就緒／啟動狀態，以及手機觸控、鍵盤與桌面；實際量測控制高度與按鍵底部，不能只看建置。
