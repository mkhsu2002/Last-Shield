**Goal:** Deliver the approved daily storm, chosen rival, and focused result flow with replay-valid scores and evidence gates.

**Architecture:** A pure daily-storm module supplies immutable date-derived profiles to shared gameplay and the server. A separate client rival model holds a day/rules-scoped snapshot without polling or affecting trace. Existing Community controller owns verified board data and optional submission; scene owns gameplay and local HUD.

**Tech Stack:** Node 24.22.3, TypeScript, Phaser, Devvit 0.15.3, Hono, Redis; no dependency upgrades.
