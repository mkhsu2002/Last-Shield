# v1.02 Reddit App 啟動畫面修正

2026-11-20。狀態：修正／驗證中，尚未發布。使用者提供 Android Reddit App 實際截圖，開始按鈕遭裁切、語言選單遮住品牌。延續已授權的正式問題修正，完成驗證後發布至原 App 與原貼文。

## 原因與修正方向

舊 splash 使用 min-height:100dvh 加上固定110px圖示、17px間距、72px上下padding與長說明，內容可高於固定的Reddit iframe；語言選單absolute佔住品牌區。前一輪驗證集中在expanded遊戲畫面，未覆蓋此啟動畫面的內容高度與字級組合。

保持現有盾牌與色系。改成固定viewport內三列：正常排版的品牌／語言列、可縮小的主視覺／短說明、不可壓縮的開始按鈕／版本列。短卡片採橫向小圖示；更短時省略次要說明與圖示，保留主要操作。不以裁字、關閉字級調整或捲動才能找到按鈕作為解法。維持同步trusted click的requestExpandedMode，遊戲、計分、排行榜與後端不變。
